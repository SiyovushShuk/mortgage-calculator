# Дополнение к ТЗ: Ипотечный калькулятор — v7 (досрочное погашение с уменьшением платежа)

Добавляем **третью вкладку** — второй вариант досрочного погашения. Теперь их два:

| Вкладка | Что фиксируем | Что меняется |
|---|---|---|
| "Досрочное погашение с уменьшением срока кредита" (v5–v6, уже реализовано) | Ежемесячный платёж | Срок кредита (сокращается) |
| **"Досрочное погашение с уменьшением платежа" (новое, v7)** | **Срок кредита** | **Ежемесячный платёж (уменьшается)** |

То есть в новом режиме кредит по-прежнему закрывается **строго за исходный
срок n**, но за счёт ежемесячной доплаты сумма самого платежа с каждым
месяцем становится всё меньше (пересчитывается).

---

## Входные данные

Те же, что и в вкладке "уменьшение срока" (см. v5):

| Параметр | Описание | Пример |
|---|---|---|
| Доп. платёж, ₽/мес | Фиксированная сумма, которую пользователь готов доплачивать каждый месяц сверх обычного платежа | 20 000 ₽ |

Остальное (сумма кредита, ставка, срок, тип платежа) берётся из основной формы.

---

## Логика расчёта (помесячная симуляция с пересчётом платежа)

Ключевое отличие от режима "уменьшение срока": там платёж P считался **один раз**
по исходной формуле и не менялся весь срок. Здесь платёж **пересчитывается заново
каждый месяц** — исходя из текущего остатка долга и **оставшегося** количества
месяцев до исходного срока n. Так кредит гарантированно закрывается ровно
за n месяцев, а платёж плавно уменьшается быстрее, чем без доплат.

### Для аннуитетного платежа

```
Остаток = S                          // тело кредита
Месяц = 0
История = []

Пока Месяц < n:
    Месяц += 1
    Месяцев_осталось = n − Месяц + 1        // сколько месяцев осталось платить, включая текущий

    // пересчитываем аннуитетный платёж для остатка долга и оставшегося срока
    P_текущий = Остаток × [ i × (1+i)^Месяцев_осталось ] / [ (1+i)^Месяцев_осталось − 1 ]

    Проценты = Остаток × i
    Основной_долг = P_текущий − Проценты
    Остаток = Остаток − Основной_долг − Доп_платёж
    Если Остаток < 0: Остаток = 0

    Сохранить в История: { Месяц, Платёж = P_текущий, Проценты, Основной_долг, Доп_платёж, Остаток }
```

Итоговый срок здесь **всегда равен n** (кредит не закрывается раньше) — вместо
этого с каждым месяцем, где была доплата, **пересчитанный P_текущий** для
следующих месяцев становится меньше, чем был бы без доплат.

### Для дифференцированного платежа

```
Остаток = S
Месяц = 0
История = []

Пока Месяц < n:
    Месяц += 1
    Месяцев_осталось = n − Месяц + 1

    // пересчитываем фиксированную часть тела долга на оставшийся срок
    Осн_текущий = Остаток / Месяцев_осталось

    Проценты = Остаток × i
    Платёж = Осн_текущий + Проценты
    Остаток = Остаток − Осн_текущий − Доп_платёж
    Если Остаток < 0: Остаток = 0

    Сохранить в История: { Месяц, Платёж, Проценты, Осн_текущий, Доп_платёж, Остаток }
```

Обозначения новые:
- **Месяцев_осталось** — сколько месяцев осталось до конца исходного срока n
  (включая текущий), используется вместо полного n в формулах
- **P_текущий / Осн_текущий** — платёж/основной долг, пересчитанные заново
  на каждый месяц с учётом уже уменьшенного остатка

## Что показывать в результате

Аналогично вкладке "уменьшение срока" (v5), но с поправкой на то, что тут
меняется:

### 1. Сравнение "Было / Стало"

| | Без досрочного погашения | С досрочным погашением {Доп_платёж} ₽/мес |
|---|---|---|
| Срок кредита | n месяцев | n месяцев (**не меняется**) |
| Ежемесячный платёж | Фиксированный P на весь срок | Уменьшается с каждым месяцем |
| Итоговая переплата по процентам | сумма всех Проценты без доп. платежа | сумма всех Проценты с доп. платежом (меньше) |

### 2. Главный акцент — на сколько уменьшится платёж и экономия на процентах

Аналогично тому, как в v6 мы выделили "срок сократится на..." для другой
вкладки — здесь главный акцент должен быть на изменении платежа:

```
┌─────────────────────────────┐   ┌─────────────────────────────┐
│   Платёж в последний месяц   │   │   Вы сэкономите на процентах │
│                              │   │                              │
│      112 000 ₽ вместо        │   │        6 100 000 ₽           │
│      176 161 ₽ (было)        │   │  (было бы 26 278 640 ₽)      │
└─────────────────────────────┘   └─────────────────────────────┘
```

Здесь нет "сокращения срока" (он фиксирован), поэтому вместо этого крупно
показываем **насколько уменьшится сам платёж** — можно сравнить платёж
через полгода/год/несколько лет после начала доплат, либо показать график,
как он плавно снижается (см. п.3)

### 3. Подробная таблица/график по месяцам

- Таблица/график по месяцам: № месяца, платёж (пересчитанный), проценты,
  основной долг, доп. платёж, остаток
- На графике — линия **платежа по месяцам**, которая явно идёт вниз
  быстрее, чем без доплат (без доплат аннуитетный платёж был бы прямой
  горизонтальной линией)
- Полезно показать **две линии платежа** одновременно: "платёж без доп.
  платежей" (постоянная прямая) и "платёж с доп. платежами" (снижающаяся
  линия) — чтобы наглядно видеть эффект

## UX-требования

- Расчёт по кнопке (как и везде — см. v4, п.2)
- Поле "Доп. платёж" с live-форматированием (см. v4, п.1)
- Обе вкладки досрочного погашения ("уменьшение срока" и "уменьшение платежа")
  должны использовать общее поле ввода "Доп. платёж" по смыслу одинаково —
  но пользователь может задать разную сумму на каждой вкладке отдельно,
  если хочет сравнить сценарии с разными доплатами
- Стоит рассмотреть возможность в будущем добавить общий экран **сравнения
  всех трёх сценариев сразу** (без доплат / уменьшение срока / уменьшение
  платежа) в одной таблице — но это отдельная доработка, не в рамках v7
