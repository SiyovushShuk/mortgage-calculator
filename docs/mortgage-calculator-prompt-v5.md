# Дополнение к ТЗ: Ипотечный калькулятор — v5 (досрочное погашение)

Новая вкладка/секция в калькуляторе: расчёт эффекта от **ежемесячного досрочного
погашения** кредита с **уменьшением срока** (платёж остаётся прежним, срок сокращается).

---

## Входные данные

Новое поле в отдельной вкладке "Досрочное погашение" (или доп. секция под основной
формой):

| Параметр | Описание | Пример |
|---|---|---|
| Доп. платёж, ₽/мес | Фиксированная сумма, которую пользователь готов доплачивать каждый месяц сверх обычного платежа | 20 000 ₽ |

Остальные параметры (сумма кредита, ставка, срок, тип платежа — аннуитет/дифф.)
берутся из основной формы — по ним и так уже есть весь ввод.

---

## Логика расчёта (помесячная симуляция)

Формула на весь срок сразу здесь не работает — долг после каждого месяца
уменьшается на дополнительную сумму, поэтому расчёт идёт **по циклу,
месяц за месяцем**, пока остаток долга не станет ≤ 0.

### Для аннуитетного платежа

```
Остаток = S                          // тело кредита
P = аннуитетный платёж (по исходной формуле, с исходным сроком n)
Месяц = 0
История = []                         // для таблицы/графика

Пока Остаток > 0:
    Месяц += 1
    Проценты = Остаток × i
    Основной_долг = P − Проценты
    Доп_платёж_факт = min(Доп_платёж, Остаток − Основной_долг)  // не переплатить лишнего в последний месяц
    Остаток = Остаток − Основной_долг − Доп_платёж_факт
    Если Остаток < 0: Остаток = 0

    Сохранить в История: { Месяц, Платёж = P + Доп_платёж_факт, Проценты, Основной_долг, Доп_платёж_факт, Остаток }

Итоговый_срок_факт = Месяц
```

### Для дифференцированного платежа

```
Остаток = S
Осн = S / n                          // фиксированная часть тела долга (по исходному сроку n)
Месяц = 0
История = []

Пока Остаток > 0:
    Месяц += 1
    Проценты = Остаток × i
    Основной_долг = min(Осн, Остаток)
    Доп_платёж_факт = min(Доп_платёж, Остаток − Основной_долг)
    Остаток = Остаток − Основной_долг − Доп_платёж_факт
    Если Остаток < 0: Остаток = 0

    Сохранить в История: { Месяц, Платёж = Основной_долг + Проценты + Доп_платёж_факт, Проценты, Основной_долг, Доп_платёж_факт, Остаток }

Итоговый_срок_факт = Месяц
```

Обозначения новые:
- **Доп_платёж** — введённая пользователем сумма ежемесячной досрочной доплаты
- **Доп_платёж_факт** — фактически применённая сумма в этом месяце (в последний
  месяц может быть меньше введённой, чтобы не "уйти в минус" по остатку долга)
- **Итоговый_срок_факт** — реальное количество месяцев до полного закрытия кредита
  (будет меньше исходного n)
- **История** — массив по месяцам, нужен для таблицы/графика

## Что показывать в результате (все 3 варианта сразу)

### 1. Сравнение "Было / Стало"

Блок с двумя колонками рядом — без доп. платежа и с ним:

| | Без досрочного погашения | С досрочным погашением {Доп_платёж} ₽/мес |
|---|---|---|
| Срок кредита | n месяцев (исходный) | Итоговый_срок_факт месяцев |
| Итоговая переплата по процентам | сумма всех Проценты без доп. платежа | сумма всех Проценты с доп. платежом |
| Общая сумма выплат | | |

Дополнительно — крупно и заметно вывести:
- **На сколько сократился срок** (например, "срок сократится на 4 года 3 месяца")
- **Сколько получится сэкономить на процентах** (разница переплат)

### 2. Новый итоговый срок и экономия

Отдельным крупным блоком (можно тем же стилем, что и ежемесячный платёж
из предыдущего промпта — по центру, крупным шрифтом):

```
Новый срок кредита: 14 лет 9 месяцев (было 20 лет)
Экономия на процентах: 9 450 000 ₽
```

### 3. Подробная таблица/график по месяцам

- Таблица (или график) с колонками: № месяца, платёж, из него проценты,
  из него основной долг, доп. платёж, остаток долга
- По умолчанию можно показывать не все месяцы построчно, а сворачивать
  в таблицу с пагинацией/скроллом, либо график изменения остатка долга
  по месяцам (линия, стремящаяся к нулю раньше, чем без доп. платежа)
- На графике полезно показать **две линии** одновременно: "Остаток долга без
  доп. платежей" и "Остаток долга с доп. платежами" — чтобы наглядно видеть разницу

## UX-требования

- Расчёт по этой вкладке тоже происходит **по кнопке** (см. промпт v4,
  п.2) — не в реальном времени
- Поле "Доп. платёж" — с тем же live-форматированием чисел, что и остальные
  суммы (см. промпт v4, п.1)
- Если пользователь оставил поле "Доп. платёж" пустым или равным 0 — вкладка
  просто показывает исходный расчёт без досрочного погашения (либо предлагает
  ввести сумму, чтобы увидеть эффект)
- Валидация: доп. платёж не может быть отрицательным; стоит предупредить,
  если введённая сумма настолько большая, что кредит закроется в первый же
  месяц (edge case) — это нормальный результат, но полезно показать явно
