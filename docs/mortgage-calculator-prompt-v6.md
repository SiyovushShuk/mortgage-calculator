# Дополнение к ТЗ: Ипотечный калькулятор — v6 (правки к вкладке "Досрочное погашение")

Правки к уже реализованной вкладке досрочного погашения (v5).

---

## 1. Переименование вкладок/кнопок

Чтобы названия вкладок были однозначны и не путались между собой:

| Было | Стало |
|---|---|
| "Расчёт" | **"Без доп. платежей"** |
| "Досрочное" | **"Досрочное погашение с уменьшением срока кредита"** |

Так пользователь сразу видит на самих вкладках (без дополнительного клика
и чтения подсказок), что это два сравниваемых сценария — обычный расчёт
без доплат и расчёт с доплатами, сокращающими срок.

*(Если название "Досрочное погашение с уменьшением срока кредита" слишком
длинное для вкладки на мобильном экране — можно сократить видимый текст
до "Досрочное погашение" при узкой ширине экрана, но полная формулировка
должна быть доступна как заголовок самой вкладки/подсказка при наведении.)*

---

## 2. Показ базового ежемесячного платежа на вкладке

**Проблема:** при переключении на вкладку "Досрочное погашение" пользователь
не видит, какой у него обычный ежемесячный платёж (без доплаты) — это
особенно важно для дифференцированного платежа, где сумма разная по месяцам,
и не сразу понятно, "к чему" прибавляется доп. платёж.

**Требуется:**

- Сразу при открытии вкладки, ещё до ввода доп. платежа, показать базовый
  ежемесячный платёж, рассчитанный по данным из основной формы (сумма,
  ставка, срок, тип платежа):
  - Для **аннуитетного** — просто одно число: "Ваш текущий ежемесячный
    платёж: **176 161 ₽**"
  - Для **дифференцированного** — платёж в 1-м месяце и в последнем
    (т.к. он не постоянный): "Платёж в 1-м месяце: **226 667 ₽**,
    в последнем: **67 333 ₽**"
- Это значение — справочное, оно **не пересчитывается по кнопке** вместе
  с остальным расчётом, а подтягивается сразу из уже введённых на основной
  форме параметров (обновляется, если пользователь поменял их в основной форме)
- Рядом с этим блоком — поле ввода доп. платежа, чтобы пользователь сразу
  понимал контекст: "вот сколько вы платите сейчас, а вот сколько готовы
  доплачивать сверху"

## 3. Явное пояснение, что это за тип досрочного погашения

**Проблема:** на вкладке не очевидно, что именно считается — есть ведь два разных
вида досрочного погашения (уменьшение срока / уменьшение платежа), и пользователь
может не понять, какой из них тут реализован.

**Требуется:**

Прямо на вкладке, над формой ввода — короткая поясняющая подпись/подсказка:

> "Ежемесячный платёж остаётся прежним, но за счёт дополнительной суммы
> кредит будет полностью погашен раньше исходного срока."

Это отличает вкладку от гипотетического другого режима (уменьшение платежа
при сохранении срока), который здесь не реализуется — но пользователь должен
понимать, какой сценарий перед ним.

*(В сочетании с новым названием вкладки из п.1 — "Досрочное погашение с
уменьшением срока кредита" — этого пояснения плюс название должно быть
достаточно, чтобы не оставалось вопросов.)*

## 4. Усиленный визуальный акцент на сокращении срока и экономии

**Проблема:** блок с новым сроком и экономией на процентах сейчас теряется
среди остальных цифр, хотя это самое главное, ради чего пользователь
вообще открывает эту вкладку.

**Требуется:** сделать эти два числа **самыми заметными на всей вкладке** —
заметнее даже, чем сам ежемесячный платёж на основной вкладке.

- Два отдельных крупных блока рядом или друг под другом, по центру,
  крупным жирным шрифтом, акцентным цветом:

```
┌─────────────────────────────┐   ┌─────────────────────────────┐
│   Срок сократится на        │   │   Вы сэкономите на процентах │
│                              │   │                              │
│      5 лет 3 месяца          │   │        9 450 000 ₽           │
│                              │   │                              │
│  (14 лет 9 мес. вместо 20)   │   │  (было бы 26 278 640 ₽)      │
└─────────────────────────────┘   └─────────────────────────────┘
```

- Формулировка именно **"Срок сократится на ..."** (разница), а не просто
  "новый срок" — так пользователю сразу понятен выигрыш, а не просто
  абсолютное число, которое надо ещё сравнивать в уме с исходным сроком
- То же самое для экономии: главное число — **разница** между переплатой
  без доп. платежей и с ними ("Вы сэкономите..."), а рядом мельче — сами
  абсолютные цифры (было / стало) для контекста
- Расчёт разницы:
  ```
  Сокращение_срока = n (исходный срок) − Итоговый_срок_факт
  Экономия_на_процентах = Переплата_без_доп_платежей − Переплата_с_доп_платежами
  ```
